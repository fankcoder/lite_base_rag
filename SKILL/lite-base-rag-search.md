# 通用 RAG 知识检索技能 (lite_base_rag)

## 概述
调用 `lite_base_rag` 提供的向量检索服务，从本地或远程文档库中检索相关内容片段，用于回答各种知识问题。
支持文本、表格或图片内容检索，基于 RAG（Retrieval-Augmented Generation）框架。

## 适用场景
当用户提出问题时，如果答案可能存在于已索引的文档库中，可使用此技能，包括但不限于：
- 产品、项目、方案、技术文档
- 内部规范、流程、操作手册
- 案例分析、行业资料
- 教学或展示资料
- 通用知识库内容（只要已被索引）

## 前置条件
- 已克隆仓库并安装依赖：
  ```bash
  git clone https://github.com/fankcoder/lite_base_rag.git
  cd lite_base_rag
  pip install -r requirements.txt
  ```
- 已创建或加载向量数据库（Milvus、FAISS 等）
- 已对文档进行索引：
  ```bash
  python scripts/index_files.py --dir <文档目录>
  ```
- Python 虚拟环境可选，用于隔离依赖

## 执行步骤

### Step 1: 判断是否需要检索
- 用户问题涉及文档库中的内容，则进行检索
- 若为闲聊或外部信息，可跳过技能

### Step 2: 提取查询关键词
- 从用户问题中提取核心查询语句
- 尽量使用简明中文或英文表述

### Step 3: 执行检索
调用检索脚本获取相关结果：
```bash
python scripts/search_cli.py "<查询内容>" --top 5
```
**可选参数：**
- `--top N`：返回前 N 条结果，默认 10
- `--type text/table/image`：按内容类型过滤

### Step 4: 整理结果
- **必须**基于检索结果回答问题，不得编造
- 标注信息来源（文件名、页码）
- 如果未找到答案，返回提示：“知识库中未找到相关信息”
- 只返回最相关的 2-3 条结果

### Step 5: 答案格式
推荐格式：
```text
根据知识库检索结果：

【答案】
...（基于检索内容的回答）...

【来源】
- 《文件名》第 X 页
- 《文件名》第 Y 页
```

## 注意事项
- 仅能检索已索引的文档，库外问题无法回答
- 检索结果按相似度排序，靠前结果更可靠
- 若相似度低于 0.5，需谨慎引用
- 首次调用会加载 embedding 模型，可能需 10-20 秒
- CPU 推理速度约 200-500ms/查询，GPU 可更快

## 更新知识库
新增文档时执行：
```bash
python scripts/index_files.py --dir <文档目录>
```

## 支持内容类型
- **文本**：Markdown、TXT、PDF 文档
- **表格**：Excel、CSV
- **图片**：文档截图、展示资料
